## 1. Source of truth and pipeline — NORMATIVE

```

```

Outputs (committed, because `home/.config/rofi` and `home/.config/swaync` are `link` entries — the
repo files *are* the live files):

```

home/.config/swaync/assets/{glass-grain.png,switch-on.png}
```

`scripts/gen-theme.py` (python3, stdlib only, same shape as `gen-keybindings.sh`):
1. Imports `theme/enhalation/enhalation_ref.py` and uses its `load_tokens`, `derive`,
   `contrast_table`, `bake`, `png_bytes`. It does **not** re-implement colour math.
2. Placeholders: `{{token-name}}` (any resolved Mocha token or §2 derived token), `{{glyph.NAME}}`
   (the §6 table). An unknown placeholder is a hard error naming file:line. No other syntax.
3. Every generated text file starts with a one-line comment:
   `GENERATED by scripts/gen-theme.py from theme/templates/<path>.in — edit the template, not this file.`
4. Runs the contrast gate; a failing required pair aborts before anything is written.
5. `--check`: regenerate in memory; text files must match byte-for-byte; PNGs are compared by
   **decoded RGBA** (our PNGs use filter 0 only, so decode = `zlib.decompress` + drop the filter
   byte per row), because compressed bytes can differ between zlib builds. Exit 1 on any drift.
6. Prints a short report: files written, contrast minima per surface, baked-image raw-RGBA sha256.

Wiring: `scripts/hooks/pre-commit` gets a block identical in shape to the keybindings one
("…is stale — run: ./scripts/gen-theme.py"). `bin/dots doctor` gets one `chk`/`bad` line for
`gen-theme.py --check`. *(corrected 2026-09-29: the `fc-list` check for `CartographCF Nerd Font`
already exists since 8b423f4, so it is not added again.)*

## 3. Deviations from Enhalation (the desktop profile) — NORMATIVE

**DP1 — No backdrop blur.** Wayfire blur stays off (Tyler's choice). Unblurred content behind a
92%-opaque pane costs contrast, so desktop glass is `glass-fill-strong` at alpha .969
(`glass-desktop`). Contrast is measured against the worst case: the 165° sheen at its peak, over a
**white** window and over `crust` (§2 table in `--contrast`). At the design system's own .922 the
pill fails for `ink-muted` (4.07) and `danger` (3.91) over white; at .969 every used pair passes.

**DP2 — Type is Cartograph.** `CartographCF Nerd Font` replaces Geist, Geist Mono and Bricolage; its
italic takes Instrument Serif's flourish role — **only** the chip label. *(corrected 2026-09-29: it
is no longer vendored in this repo — since 8b423f4 it comes from the private
`SvnFrs/cartograph-fonts` via `fonts install`. Wherever this brief says "the vendored TTF", read
the installed file: `fc-match -f '%{file}\n' 'CartographCF Nerd Font'`, today
`~/.local/share/fonts/cartograph-cf/nerd/CartographCFNerdFont-Regular.otf`, a Nerd Fonts v3.5.1
build. Never commit a font file.)* Weights available (VERIFIED `fc-query`; re-checked on the v3.5.1
build — the Nerd family now spells the style "DemiBold", same fc weight 180):
Thin, Extra Light, Light, Regular (fc 80), Demi Bold (fc 180 = CSS 600), Bold (200), Extra Bold,
Heavy, each with italic. Roles:

| Role | Enhalation | Desktop |
|---|---|---|
| menu row, notification body | body 15px / 400 | Regular 11pt in rofi (≈14.7px); 14px in swaync |
| selected row, notification summary | 600 | Demi Bold (Pango `Semi-Bold`), same size |
| chip label (flourish) | Instrument Serif italic | Bold Italic 11pt |
| panel title ("Notifications") | title 24px / 600 | Demi Bold 20px (monospace runs wide) |
| time, counters | caption 12px / 460 | Regular 12px, `ink-muted` |

Fallback family everywhere: `JetBrainsMono Nerd Font` (for Nerd v3 glyphs and Vietnamese, §6).
Body stays monospaced so `actions.sh cal` keeps its columns.

**DP3 — rofi has no shadows.** No `glass-float` in rofi (rofi-theme has no box-shadow). Depth comes
from the `rim` ring plus a lit top line (§4.1). swaync keeps the full `glass-float`.

**DP4 — rofi cannot reference variables inside gradients or `highlight`** (VERIFIED earlier;
`clipboard.rasi` already documents the `highlight` case). Generated `.rasi` files therefore contain
**literal values only** — no `@variables`, no `@import` of palettes. Each starts with
`@theme "/dev/null"` so rofi's built-in theme cannot leak in (the pattern `clipboard.rasi` already
uses).

**DP5 — Controls on glass are glass-native.** Enhalation forbids clay controls and clay shadows on
glass (Glass README: "Never put clay shadows or clay controls on glass"). Every hollow on a panel is
a `well` (`glass-shade` fill, `well-shadow` in GTK); knobs are the radial `thumb` with `thumb-shadow`
(the design system's own on-state knob shadow), never `clay-sm`; buttons are `pill`s. No
`clay-raised/lift/pressed/well/sm` value appears in any generated file.

**DP6 — Grain is baked.** Neither GTK4 nor rofi has `mix-blend-mode` (GTK: VERIFIED earlier from the
GTK CSS property list). `enhalation_ref.py --bake` renders the exact overlay composite (W3C
Compositing §5.8 formula) into PNGs: `glass-grain.png` (220×220 repeatable tile, `glass-desktop` +
grain at .12) and `switch-on.png` (56×32, `core-gradient` + grain at .22, tile scaled to 160px as
in the Switch component). Checked here against Chromium's live `mix-blend-mode: overlay` render:
mean colour within 0.6 levels (of 255) and the same spread (VERIFIED, `bakecmp` 2026-09-29). rofi's chip
stays a flat gradient unless §9 I6 proves rofi can load an image from a repo-relative path.

**DP7 — Motion.** rofi has none of its own (it appears and leaves through Wayfire's overlay fade).
swaync: enter = CSS keyframes, 280ms `ease-out-expo` (opacity 0→1, translateY −6px→0; the control
centre also scale .97→1). Leave cannot be styled in GTK CSS (the surface unmaps), so leave speed is
set where it lives: `config.json` `transition-time` 150 and `wayfire.ini [animate] fade_duration`
150. The Wayfire fade is symmetric; with the 280ms CSS enter layered on top, "enter slow, leave
fast" still holds. Hover 180ms `ease-out-expo`; press 90ms `ease-press`. GTK's switch knob travel is
internal — no spring.

**DP8 — Moments and colour roles.** One warm core per view:
- rofi: the chip (glyph + label) of launcher, window switcher, clipboard.
- swaync: the Do-not-disturb switch **when on**. Nothing else in swaync is warm.
- `clip-del` replaces the warm chip with a **danger** chip (destructive intent outranks the moment).

`accent` (mauve) = match highlights, volume fill, today in `cal`, focus. `spark` (teal) = exactly
one thing: the focused window's row in the window switcher (rofi `active` state) — it carries over
the teal the old switcher used for the wallpaper. Pink as an *accent* (the old launcher) is retired;
pink now lives inside the warm core. `danger` = urgent rows, critical notifications, `clip-del`.

### 3.4 Pairing rules — NORMATIVE
- A hover or selection **replaces** a surface's fill, it never stacks: a hovered cell is `pill`, not
  `pill` over `cell`. `pill`-over-`cell` fails for `ink-muted` (4.29) and `danger` (4.12) over white,
  so those two pairs must never appear.
- Text on the warm core is `on-halo` only. Display type never sits on the warm core (the chip label
  is 11pt, not display).
- Status never relies on hue alone: urgent rows keep their title text; critical notifications keep
  their summary; `clip-del` shows the trash glyph **and** a word.
