# Capture UI — screenshot overlay and recording island

**Status:** Proposed · **Date:** 2026-09-29 · **Owner:** Tyler (@SvnFrs)
**Depends on:** `docs/enhalation-desktop.md` (tokens, generator, desktop profile, §3.4 pairing rules).
**Visual target:** `docs/capture-ui-preview.png` (a browser mock; the desktop behind it is fake).

The NORMATIVE sections are the contract. Tool claims carry VERIFIED (how) or INFERRED (from what),
and every INFERRED item is repeated in §9 and checked on the machine.

## 0. Why and what

Today capture is four keybindings into `swaync/actions.sh` (`shot`, `snip`, `rec`, `rec-area`),
`slurp` for areas, and a critical notification standing in for the recording indicator. It works,
but it is keyboard-first, and a mouse-first user has no visual way in. This adds two surfaces:

1. **Capture overlay**: a GNOME-style screenshot UI. The screen freezes, you pick
   Area / Screen / Window and Photo / Video on a glass toolbar, and click the shutter.
2. **Recording island**: a "● REC 00:42" pill pinned in the top-left corner, like a camcorder
   viewfinder. Clicking it morphs it into a Dynamic-Island card with Stop and save / Discard. After
   Stop it shows a saved state.

Unchanged: `actions.sh` stays the only thing that runs `grim`, `slurp` and `wf-recorder`, including
its four documented bug fixes and its log. Every current keybinding still works if the UI is not
running.

## 1. Toolkit — Quickshell (decision; Tyler confirms at C0)

| | Quickshell | GTK4 + Python (gtk4-layer-shell) |
|---|---|---|
| Island morph (width, height and radius together, spring) | native (`Behavior` + `SpringAnimation` / bezier easing) | `GtkRevealer` does one axis with fixed easing; a real morph means custom drawing |
| Selection overlay with handles | QML items + `MouseArea` | `GtkDrawingArea` + cairo + gestures |
| Enhalation easing `cubic-bezier(0.16,1,0.3,1)` | `Easing.BezierSpline` | not available in GTK CSS transitions for size |
| New dependencies | quickshell + Qt6 (base, declarative, wayland, svg) | none (gtk4 and gtk4-layer-shell are already swaync's deps) |
| Theme from the same tokens | `Theme.qml` generated by `gen-theme.py` | the GTK CSS the generator already writes |

VERIFIED 2026-09-29: `quickshell 0.3.1-1` is in Arch **extra** (updated 2026-08-21; deps qt6-base,
qt6-declarative, qt6-svg, qt6-wayland, jemalloc, libpipewire …). `IpcHandler` exposes typed
functions, called with `qs ipc call <target> <function> <args>`. `ScreencopyView` needs
`wlr-screencopy-unstable-v1` (Wayfire has it; `grim` works) — but this design does not need it
(§2.3). Per-window capture (`Toplevel`) needs `hyprland-toplevel-export-v1`, which Wayfire does
not have, so Window mode uses Wayfire IPC geometries instead (§2.4).

Recommendation: Quickshell. The morph and the overlay are the whole point, and both are natural in
QML. If Tyler declines, stop: this document would need its §2 rewritten for GTK4.

## 2. Architecture — NORMATIVE

### 2.1 Files
```
home/.config/quickshell/enhalation/            (new `link` entry in dots.conf)
  shell.qml              one ShellRoot: CaptureOverlay (per screen) + RecIsland
  Theme.qml              GENERATED by scripts/gen-theme.py from theme/templates/quickshell/Theme.qml.in
  CaptureOverlay.qml, Toolbar.qml, Segmented.qml, RecIsland.qml, GlassPanel.qml
  assets/                GENERATED: glass-grain.png (existing bake), shutter-60.png, core-stop.png (§4.4)
home/.config/ipc-scripts/capture-views.py      Wayfire IPC → JSON of capturable windows (§2.4)
```
Started from `wayfire.ini [autostart]` (`capture-ui = qs -c enhalation`, INFERRED flag, check
`qs --help`). `scripts/packages/desktop.txt` gains `quickshell`; `dots doctor` gains one check that
it is running.

### 2.2 Control flow (actions.sh stays the backend)
New `actions.sh` verbs, logged like the rest:

| Verb | Does |
|---|---|
| `capture-open <area\|screen\|window> <photo\|video>` | `close_panel`; `sleep 0.25` (the existing lesson); `grim` the focused output to `$XDG_RUNTIME_DIR/capture/freeze.png` and, with `-c`, to `freeze-cursor.png`; then `qs -c enhalation ipc call capture show <mode> <kind>`. If `qs` fails, fall back to the old path (`snip` / `shot` / `rec-area` / `rec`) so a key press never does nothing |
| `shot-crop <x> <y> <w> <h> [cursor]` | crop the freeze (physical px) into `$PIC/<date>.png`, `wl-copy -t image/png`, toast **with the image** (`notify-send -i "$F"`) |
| `rec-start [geometry]` / `rec-stop` / `rec-discard` | today's `rec_start` / `rec_stop` bodies, plus the state file below. `rec-discard` = `rec-stop`, wait for wf-recorder to exit, then delete that one file |
| `rec` / `rec-area` | unchanged meaning (toggle), now via the verbs above |

State file (atomic write: tmp + `mv`): `$XDG_RUNTIME_DIR/capture/rec.json`
`{"state":"recording|saved|failed","file":"…","started":<epoch ms>,"mode":"screen|area","geometry":"x,y WxH|null","audio":"desktop","size":<bytes|null>,"duration_ms":<int|null>,"log":"…"}`.
The island watches it (Quickshell `FileView`, watching for changes), only reads it, and never runs
a recorder itself. `saved` and `failed` are written by `rec-stop` and `rec-start`; the island hides
6 s after showing them, and the next `rec-start` overwrites the file.

Indicator fallback: `rec-start` sends the old critical "REC" notification **only** when the
island is not running (`qs -c enhalation ipc call rec ping` fails), so there is never both.

### 2.3 Freeze, then crop (photo)
The overlay shows `freeze.png` full-screen (a plain `Image`), so what you select is what you get —
menus and tooltips included. The selection is in logical px; `shot-crop` receives physical px
(`× screen scale`). Crop with `ffmpeg -i freeze.png -vf crop=w:h:x:y` (`ffmpeg` should be present
as a wf-recorder dependency, INFERRED) or ImageMagick if installed — pick one at C0, record it.
Pointer toggle ON → crop `freeze-cursor.png` instead. Both frames are taken before the overlay maps,
so the overlay can never be in the picture.

Video mode does not freeze: the overlay shows the live desktop (transparent surface, scrim only
outside the selection), and on the shutter it leaves (150 ms) **before** `rec-start` runs.
wf-recorder has no cursor option (VERIFIED: none in `wf-recorder(1)` 0.6.0), so in Video mode the
Pointer toggle is shown ON and disabled ("always recorded", INFERRED — confirm with a 3 s test).

### 2.4 Window mode
`capture-views.py` (python-wayfire, stdlib otherwise) prints the mapped toplevel views on the
focused output's current workspace: `id, app_id, title, geometry {x,y,w,h}` in logical px,
**top-most first** (stacking order; the same rule spread-overview's hit-testing uses). Hover
highlights the top-most view under the pointer; click captures its rectangle from the freeze.
Limitation (accepted): it captures the visible pixels, so an overlapping window shows through.

### 2.5 Screens
One overlay per output (`Variants` over `Quickshell.screens`); the selection lives on one output.
kanshi profiles normally leave one output on, so this is rarely visible. Screen mode = click an output.

## 3. Capture overlay — design, NORMATIVE

Layer `overlay`, exclusive keyboard focus while open, full-screen on each output.

| Part | Spec |
|---|---|
| Backdrop | `freeze.png` (photo) or transparent (video) |
| Scrim | outside the selection: `capture-scrim` = `ground-deep` ×.55 → `#11111b8c` (new derived token). Inside: clear |
| Selection | 1.5 px `ink` at 90%, radius 2. Corner handles 12 px circles: `radial-gradient(thumb-hi → ink)`, `thumb-shadow`. Hit targets 24 px; edges resize, inside drags. Last area remembered for the session |
| Size chip | glass pill below-right of the selection, caption 12 px, `640 × 360` in physical px |
| Hint | glass pill 8 px above the toolbar, caption `ink-muted`: "Drag to select · drag inside to move · Enter captures · Esc cancels". Hidden after the first drag. Never bare text on the scrim (fails contrast over white content) |
| Toolbar | glass (fill, sheen, grain, rim, `glass-float`), radius 26, padding 10, bottom-centre, 24 px above the edge |
| Mode | segmented, glass-native: `well` track + `well-shadow`, radius 16, pad 4; options 40 px tall, radius 12, glyph + word; selected = `pill` + `pill-top`, `ink`, Demi Bold; others `ink-muted`. Area U+F125, Screen U+F108, Window U+F2D2 |
| Shutter | 60 px circle, **the warm core** (baked `shutter-60.png`, §4.4) + `halo-glow`; glyph `on-halo` 22 px: camera U+F030 (photo), circle U+F111 (video). Hover: `halo-glow-lift`; press: scale .972, 90 ms `ease-press` |
| Kind | segmented like Mode: Photo U+F03E, Video U+F03D |
| Pointer | ghost button (glyph U+F245 + word). ON = `pill`, glyph `accent`. Video: ON + disabled (`opacity-disabled` .42) |
| Close | 40 px glass circle, U+F00D |
| Window-mode hover | 2 px `accent` outline on the view + glass chip with `app_id` at its top-left |
| Keys | Enter/Space capture, Esc cancel. Nothing else (mouse-first) |
| Motion | enter: scrim fade 180 ms; toolbar rise 12 px + fade, 280 ms `ease-out-expo`. Leave: 150 ms `ease-exit`. The segmented pill glides between options: 420 ms `ease-spring` |

## 4. Recording island — design, NORMATIVE

Layer `overlay`, top-left, margins 16 px (`space-4`), no keyboard focus, input mask = the island's
own shape (clicks elsewhere go to the apps underneath).

### 4.1 States
1. **Collapsed**: pill 36 px tall, radius full, padding 0 14 0 12, glass. `●` 10 px `danger` +
   `0 0 10px danger×.6` glow, breathing (opacity 1 ↔ .4, 1.2 s, ease-in-out, alternate). `REC` Bold
   13 px, tracking .08em. Timer `mm:ss` (`h:mm:ss` past an hour) Regular 13 px `ink`, from
   `started`, updated each second. Hover: fill → `pill-hover` over glass, 180 ms; pointer cursor.
2. **Expanded** (click the pill): width 368, padding 16, radius 26.
   - Header: dot, "Recording" Bold 14, chip (`pill`, caption `ink-muted`) "Area 640×360" or
     "Screen", timer Regular 28 px right-aligned.
   - Meta (caption `ink-muted`): U+F028 "Desktop audio", then the file name, ellipsized in the middle.
   - Actions: **Stop and save** = warm core (baked `core-stop.png`, radius 12, height 42, flex) with
     U+F04D; **Discard** = glass button, U+F1F8 in `danger`, word in `ink`.
3. **Discard armed** (first Discard click, 3 s): no warm core. "Keep going" (glass, U+F04B) +
   "Delete it" (`danger-soft` + `danger-rim` ring, U+F1F8 `danger`, word `ink`). Timeout or Keep going
   → back to 2. Delete it → `rec-discard` → the island leaves.
4. **Saved** (after Stop): U+F00C in `spark` (the view's one cool mark), "Saved", chip
   "00:42 · 12.4 MB", full path in caption, actions Play (`xdg-open file`), Show in folder
   (`org.freedesktop.FileManager1.ShowItems` over D-Bus if a file manager provides it, else
   `xdg-open dir`), Copy path (U+F0C5, `wl-copy`). Leaves after 6 s; hovering holds it.
5. **Failed**: like Saved but U+F071 in `danger`, "Recording failed", "Open log" (`xdg-open` the
   actions log). Replaces today's "KHOI DONG THAT BAI" notification.

### 4.2 Motion
- Collapsed ↔ expanded: width, height and radius animate **together**, 420 ms `ease-spring` open
  / 280 ms `ease-out-expo` close. Contents crossfade 180 ms, starting 120 ms into the open.
- Collapse when the header is clicked, or 2 s after the pointer leaves an expanded island. No
  full-screen click catcher: it would eat clicks meant for apps.
- Appear: 280 ms (scale .92 → 1 + fade, from the corner). Leave: 150 ms `ease-exit`.

### 4.3 Honest limits
- A **full-screen recording includes the island** (it is an ordinary layer surface, and
  wlr-screencopy copies the composited output). Area recordings exclude it when the area misses the
  top-left corner. (Fork idea, §10.)
- wf-recorder 0.6.0 has no pause (VERIFIED: not in `wf-recorder(1)`), so the island has none.

### 4.4 Baked warm-core images
Extend `enhalation_ref.py` with `bake_core(w, h, radius, grain_px, strength)`: the 115°
`core-gradient` + overlay grain (same formula as `switch-on.png`), with an anti-aliased rounded
shape baked into alpha (4×4 supersampled coverage). Outputs: `shutter-60.png` (60×60, circle, grain
160 px, .22) and `core-stop.png` (the Stop button's exact size at the island's fixed width,
radius 12, grain 180 px, .22). Add their digests to the `--digest` output and to this file.

## 5. Contrast — NORMATIVE additions to the gate
Every text pair above is already in the gate (glass, pill, well, danger-soft with ink / ink-muted /
spark / danger; on-halo on the warm core) except one new surface: the selected segment is a `pill`
**over a `well`**. Add surface `pill-on-well` = pill over (well over glass) and the pair
`(pill-on-well, ink)` to `REQUIRED`; it must pass on both backdrops. The scrim is never a text
surface (§3 "Hint"), and nothing may use a pair listed in `FORBIDDEN`.

## 9. INFERRED — check at C0 or the increment that uses it
- `qs -c <name>` selects a config under `~/.config/quickshell/<name>/`, and `qs -c <name> ipc call …` targets it.
- PanelWindow input mask (`mask: Region { item: … }`) limits clicks to the island.
- `FileView` change-watching works on `$XDG_RUNTIME_DIR` (tmpfs).
- `ffmpeg` CLI present (wf-recorder dependency).
- wf-recorder records the cursor (no flag either way).
- python-wayfire exposes view geometry and stacking order for `capture-views.py`.
- `Quickshell.screens` gives each output's scale for logical → physical crop.
